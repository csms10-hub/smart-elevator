원격 연결 (Firebase 실시간 데이터베이스)

연결 방법 보기
  1. ESP32는 2.4GHz Wi-Fi만 됩니다. 학교 5GHz 대신 휴대폰 핫스팟(2.4GHz)에 연결해요.
  2. Firebase 콘솔 → 프로젝트 만들기 → Realtime Database → 데이터베이스 만들기 (위치: 싱가포르)
  3. 규칙 탭에 아래를 붙여넣고 게시
    {"rules":{"elevator":{".read":true,".write":true}}}
  4. 데이터베이스 주소를 복사해 위 칸과 아두이노 코드의 FIREBASE_URL에 넣어요.
  5. PC·휴대폰은 학교 5GHz Wi-Fi나 LTE/5G 데이터 어디서든 이 페이지로 조작할 수 있어요.
